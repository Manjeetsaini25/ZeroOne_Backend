# 🚀 Project Name

Zero One --- A Coding platform where you can solve problems related to Data Structure.

## 🛠️ Tech Stack

* JavaScript
* node.js
* express.js
* Redis
* Jwt
* Axios
* MongoDB
* Validator
* Bcrypt
* Gemini Api
---

## 📂 Clone the Repository

```bash
git clone https://github.com/Manjeetsaini25/ZeroOne_Backend.git
```

Move into the project directory:

```bash
cd ZeroOne_Backend
```
---

## 📦 Install Dependencies

```bash
npm install
```

---
⚙️ Environment Variables
Create a .env file in the root directory. Ensure, you have same services key as present in .env.example.

## ▶️ Run the Project

```bash
node src/index.js
```

The application will start on:
```
http://localhost:3000
```
